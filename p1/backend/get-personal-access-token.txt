A personal access token (PAT) is an automatically generated passsoword that lets you access
Git based resources in Azure Dev Ops.

If you already have one, enter it below.

If you do not have one, follow the steps below to generate one.

1. Login to Azure DevOps
2. Go to User Settings (top-right, beside help)
3. Click on Personal access tokens
4. Click on New Token
5. Configure Name and Expiration

Check that the Scopes field is set to Custom defined

6. Check Packaging > Read
7. Click on Create
8. Add the new token to your password manager
